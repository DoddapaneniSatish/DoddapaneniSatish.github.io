# Satish Doddapaneni — Portfolio

Personal portfolio featuring data engineering, analytics, and applied machine learning projects.

## Website

This repository is prepared for GitHub Pages. Publish from the `main` branch and the repository root (`/`).

## Files

- `index.html`: portfolio content and project gallery.
- `style.css`: responsive dark/light themes and project artwork.
- `app.js`: interactive data sculpture, project filtering, case studies, mobile navigation, and theme switching.
- `satish-doddapaneni-resume.pdf`: downloadable resume.
- `.nojekyll`: serves this site directly as static files.

No build tools, API keys, or dependencies are required. Edit these files and commit to `main` to update the published site.
